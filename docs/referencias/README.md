# Referências

## Capturas do sistema de referência

A pasta `imagens de referencia/` contém **38 capturas de tela do Tailor**
(`app.usetailor.com.br`), obtidas em reunião de apresentação em 07/08/2026.

⚠️ **Estas imagens não estão versionadas** (ver `.gitignore`), por dois motivos:

1. **Peso** — 89 MB de PNG. O git guarda o histórico para sempre; quem clonar o repositório daqui a
   dois anos ainda baixaria tudo.
2. **Natureza** — são telas de produto de terceiro, capturadas em contexto de reunião comercial.
   Não é material nosso para redistribuir.

## Onde está o conteúdo delas

**Tudo o que importava já foi extraído** para
[`../inventario-funcionalidades-referencia.md`](../inventario-funcionalidades-referencia.md):

- Árvore completa de navegação, web e mobile
- Cada tela, com elementos, filtros, colunas, badges e estados
- As regras de negócio que as telas revelam sem dizer
- Volumes reais observados — que viraram requisitos não-funcionais
- O que o sistema **não** faz, e por que isso importa

A análise competitiva derivada está em [`../concorrentes-tailor.md`](../concorrentes-tailor.md).

## Se precisar das imagens

Elas continuam no diretório local de quem as recebeu. Para reproduzir a análise, o método está na
skill [`levantar-requisitos`](../../.claude/skills/levantar-requisitos/SKILL.md), seção
"Analisar um sistema a partir de capturas".
